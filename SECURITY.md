# Security policy

## Supported versions

Security fixes are targeted at the latest public Cammetry release and the current `main` branch.

## Reporting a vulnerability

Please avoid posting sensitive vulnerabilities, private GPS coordinates, vehicle recordings, or credentials in a public GitHub issue.

Until a dedicated security contact is configured, use GitHub's private vulnerability reporting feature if it is enabled for the repository. Otherwise contact the project maintainer through the private contact method listed on the maintainer's GitHub profile.

Include:

- affected Cammetry version;
- operating system;
- clear reproduction steps;
- expected vs. actual behavior;
- whether private footage, GPS data, arbitrary file access, command execution, or network transmission is involved.

## Scope

Examples of security-relevant issues include unsafe file handling, unexpected uploads, path traversal, command injection, malicious media handling, insecure update behavior, and leakage of GPS/video data.
