# GitHub repository setup checklist

Repository: `anivdas/Cammetry`

Suggested description:

> Free, open-source TeslaCam viewer, telemetry explorer and multi-camera exporter. Local-first, privacy-focused, no Tesla account required.

Suggested topics:

`tesla` `teslacam` `dashcam` `telemetry` `sei` `ffmpeg` `python` `windows` `video` `open-source` `privacy`

Recommended settings:

- Public repository
- Issues enabled
- Discussions enabled (optional but useful)
- Private vulnerability reporting enabled
- Preserve release artifacts via GitHub Releases
- Branch protection for `main` once outside contributors appear
- Require pull request review later if the project gains maintainers

Suggested About link: the Cammetry page on the maintainer's site once published.

Do not describe the project as official Tesla software or as a fork of another TeslaCam application.
